# 필요한 API 목록

## 인증

- 회원가입
- 로그인 (이메일/비밀번호) - SNS 로그인만 처리할거면 만들필요 X
- 소셜 로그인 (카카오, 네이버, 애플, 구글)
- 토큰 갱신
- 로그아웃
- 비밀번호 재설정

## 사용자

- 내 정보 조회/수정
- 회원 탈퇴

## 경매

OPEN API
https://www.data.go.kr/tcs/vas/selectVisualizationListView.do (동산 데이터는 여기서 가져와야 할듯?)
https://data.iros.go.kr/ (여기는 부동산 데이터)

주의할점 OPEN API다보니 요청횟수 제한이 있어서 서버에서 캐싱전략으로 가져와야 할듯

- 경매 목록 조회 (타입, 지역, 날짜, 가격 필터 + 정렬)
- 경매 상세 조회
- 경매 검색 (키워드)
- 날짜별 경매 목록
- 월별 경매 있는 날짜 목록 (캘린더용)
- 법원 목록
- 지역 코드 목록 (시도/시군구)

## 관심 목록

- 관심 목록 조회
- 관심 추가/제거
- 관심 ID 목록 조회 (앱 초기 로딩용)

## 최근 본 경매

- 최근 본 목록 조회
- 조회 기록 추가 (상세 진입 시)
- 전체 삭제

## 홈 데이터

- 대시보드 통계 (부동산 건수, 전주 대비)
- 뉴스 목록
- 오늘의 퀴즈 조회 + 답변 제출

## 알림

- 알림 목록 조회
- 알림 읽음 처리
- 알림 설정 조회/수정
- EXPO TOKEN 푸시 토큰 등록

- 이용약관 / 개인정보처리방침
- 앱 버전 정보 (강제 업데이트 팝업 처리 할거면 필요)
